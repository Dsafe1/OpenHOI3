Dear ImGui in OpenHOI3

A mod's own windows in OpenHOI3's enhanced mode are drawn with Dear ImGui (docs/mechanics/modwindows.md). This
folder is "Dear ImGui for Godot" (imgui-godot), version 6.3.2, its C#-only package as released, unchanged:

  https://github.com/pkdawson/imgui-godot    MIT licence, LICENSE.txt beside this file

It is somebody else's code kept here as it came: the rule of one type to a file, and this project's other rules of
style, are not applied to it. To move to a newer version, replace the folder's contents with that release's
addons/imgui-godot and keep this file and LICENSE.txt.

It rests on these, which come with the build as libraries (cimgui.dll, ImGui.NET.dll), each under the MIT licence:
